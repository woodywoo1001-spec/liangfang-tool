# 量房工具

## 📐 智能量房测绘本

一款基于 Web 的量房工具，适合设计师、装修工人现场测量使用。

### 功能

- **XYZ 三轴测量**：支持平面 X/Y 轴 + 高度 Z 轴（层高记录）
- **毫米精度**：所有数据以毫米为单位
- **任意多边形**：逐段拼接墙体，支持 L 形、凹凸不规则房间
- **门窗标记**：每面墙可设置门/窗位置，画布上可视化显示
- **现场拍照**：每面墙可关联多张现场照片（支持相机/相册）
- **高程标注**：梁底高、窗台高、窗顶高、门高等信息
- **不规则标记**：凸起、凹陷、梁柱等标记点
- **自动居中**：终点始终在画面中心，10 秒空闲自动回归
- **导出 JPG/PDF**：A4 尺寸高清输出
- **项目打包**：导出为 .zip（含 JSON 数据 + 所有照片），可跨设备导入
- **触屏适配**：双指缩放/平移，拖拽绘制，适配手机 Safari / Chrome

### 使用方式

直接在浏览器打开 `量房工具.html`，或部署到服务器后通过手机访问。

手机端需要 HTTP 服务器（因相机 API 需要安全上下文），推荐使用 GitHub Pages：

```
https://woodywoo1001-spec.github.io/liangfang-tool/
```

### 本地开发

```bash
# 启动本地服务器（手机可局域网访问）
chmod +x serve.sh
./serve.sh
```
